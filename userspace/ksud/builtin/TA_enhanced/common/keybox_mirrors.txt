# keybox 镜像源清单（中国大陆优先）
# ============================================================================
# 用法：每行一个 HTTPS URL；空行与本注释块以外，# 开头的整行会被忽略。
# **不要写行尾注释**（解析器会把整行当 URL）。
# 设备端按顺序尝试，单源超时见 KB_URL_TIMEOUT（默认 20s），一轮总预算见
# KB_SWEEP_BUDGET（默认 240s）；最近一次成功的源会被记住并在下一轮排到最前。
# 用户可以在 /data/adb/.xudc_secure/keybox/mirrors.txt 追加自己的源，
# 该文件里的源会跟在下面这些之后（同样支持 # 整行注释）。
#
# 顺序依据：
#   1) yurikey 原始源（base64）via 国内 GitHub 代理——最"新鲜"，代次最高；
#   2) 本项目 keybox 分支（CI 每 15 分钟把上面那份解码后镜像过去）via 国内代理；
#   3) jsDelivr 三个 CDN 域名（国内时通时断，放后面）；
#   4) 直连 raw.githubusercontent.com（海外/VPN 场景，国内基本不可达）。
# 注意：源是否"新鲜"以 DeviceID 里的 YurikeyNN 代次为准——代次更低一律拒绝，
# 更高直接采纳，同代次默认跳过（只在实时副本超期时才采纳同代次的新内容）。
# 详见 keybox.sh::kb_try_candidate。
# ============================================================================
